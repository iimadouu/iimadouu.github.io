The approach

What this actually looks like.

Your website is not a brochure, it is software. I write it by hand in HTML, CSS and JavaScript so it loads in under a second on a normal Algerian mobile connection, works on every screen, and does not break when you need to change something.

Frontend work here means a lot of unglamorous things done properly: semantic markup search engines can read, forms that actually deliver, images that are compressed, focus states and contrast that make the site usable for everyone. Those details are the difference between a site that looks fine and one that earns money.

Behind it, when you need accounts, stored data or dashboards, I connect the frontend to Firebase or to a custom backend I build myself — so the site is one system instead of three tools stitched together.

Questions

Asked, answered.

How much does a website cost in Algeria?

A static landing page or small site starts at 40,000 DZD and usually sits between 40,000 and 70,000 DZD. A dynamic site with a login and dashboard is typically 90,000–180,000 DZD. Advanced platforms with e-commerce and integrations range from 225,000 to 450,000 DZD.

Do you use WordPress or page builders?

I build sites by hand in HTML, CSS and JavaScript, which gives better speed, security and control than a page builder. If your project genuinely needs WordPress or another CMS, I will say so rather than force my stack.

Will my website appear on Google?

Every site ships with clean titles, meta descriptions, structured data, a sitemap and fast loading — the technical foundation Google needs to index it. Ranking beyond that depends on content, competition and links over time, so I never promise a position.

Do you handle hosting and the domain?

I set up and deploy the site and guide you through choosing and connecting a domain. Static sites can even be hosted for free through GitHub Pages or Cloudflare.

Can you work with my existing design?

Yes. If you already have a design in Figma or a PDF, I can build it exactly, or improve the parts that will not work well on mobile.
